# cae-assets

Public image assets for CyberAgents Exchange community posts. Files here are referenced by
URL (Discord can't attach an uploaded file to a Components V2 webhook message), so **never
rename or delete a file that a posted message points at**; add a new file instead.

## discord/ai-in-security-news/

measured 400 px display width, 2x). Sources live with the discord-newsletter skill.
